# AI Football Lab

Экспериментальная система анализа футбольных матчей.

## Назначение проекта

AI Football Lab предназначен для проверки аналитической модели, которая:

- получает список футбольных матчей;
- отбирает события с достаточным объёмом данных;
- анализирует форму команд;
- учитывает домашние и выездные показатели;
- оценивает турнирную мотивацию;
- определяет уровень риска;
- публикует ограниченное количество прогнозов;
- сохраняет всю историю без удаления неудачных результатов;
- рассчитывает виртуальный банк и статистику модели.

## Текущий этап

На первом этапе создано:

- адаптивное одностраничное приложение;
- современный интерфейс;
- раздел текущих прогнозов;
- виртуальный банк;
- график динамики банка;
- статистика точности;
- история прогнозов;
- фильтрация по результатам;
- автоматическая публикация через GitHub Pages.

## Текущие данные

На данном этапе используются демонстрационные данные.

Они нужны для проверки:

- внешнего вида;
- адаптивности;
- логики отображения;
- графика;
- статистики;
- истории прогнозов;
- GitHub Pages.

## Следующий этап

Следующий крупный этап включает:

- загрузку реальных футбольных матчей;
- подключение источника спортивных данных;
- исключение неподходящих соревнований;
- анализ через модель OpenRouter;
- автоматическое формирование прогнозов;
- автоматическое обновление результатов;
- пересчёт виртуального банка;
- накопление статистики;
- ежедневный запуск через GitHub Actions.

## Важное предупреждение

Проект является экспериментальным.

Материалы сайта:

- не гарантируют выигрыш;
- не являются финансовой рекомендацией;
- не являются призывом к азартным играм;
- не используют реальные денежные средства.

Виртуальный банк предназначен исключительно для проверки качества аналитической модели.
---

## Реальный автоматический контур

Добавлен автоматический аналитический pipeline:

1. GitHub Actions запускает обработку вручную или ежедневно.
2. Football-Data предоставляет реальные матчи и результаты.
3. Система собирает недавнюю форму команд.
4. Матчи без достаточного объёма данных исключаются.
5. OpenRouter анализирует только подготовленные числовые показатели.
6. Система может вернуть пустой список, если надёжных вариантов нет.
7. Результат записывается в `data/state.json`.
8. Завершённые прогнозы автоматически получают результат.
9. Виртуальный банк и статистика пересчитываются.
10. GitHub Pages автоматически получает обновлённый JSON из ветки `main`.

## Секреты GitHub

Необходимо добавить:

- `FOOTBALL_DATA_API_KEY`
- `OPENROUTER_API_KEY`

Дополнительно можно создать переменную репозитория:

- `OPENROUTER_MODEL`

Если `OPENROUTER_MODEL` не задана, OpenRouter использует модель,
настроенную в аккаунте по умолчанию.

## Коэффициенты

Система пока не получает букмекерские коэффициенты.

Показываемый коэффициент является расчётным справедливым коэффициентом:

`1 / вероятность модели`

Он используется только для внутреннего виртуального тестирования и
не должен восприниматься как доступный рыночный коэффициент.
