# AI Football Lab

Экспериментальная система анализа футбольных матчей.

## Назначение проекта

AI Football Lab предназначен для проверки аналитической модели, которая:

- получает список футбольных матчей;
- отбирает события с достаточным объёмом данных;
- анализирует форму команд;
- учитывает домашние и выездные показатели;
- оценивает турнирную мотивацию;
- определяет уровень риска;
- публикует ограниченное количество прогнозов;
- сохраняет всю историю без удаления неудачных результатов;
- рассчитывает виртуальный банк и статистику модели.

## Текущий этап

На первом этапе создано:

- адаптивное одностраничное приложение;
- современный интерфейс;
- раздел текущих прогнозов;
- виртуальный банк;
- график динамики банка;
- статистика точности;
- история прогнозов;
- фильтрация по результатам;
- автоматическая публикация через GitHub Pages.

## Текущие данные

На данном этапе используются демонстрационные данные.

Они нужны для проверки:

- внешнего вида;
- адаптивности;
- логики отображения;
- графика;
- статистики;
- истории прогнозов;
- GitHub Pages.

## Следующий этап

Следующий крупный этап включает:

- загрузку реальных футбольных матчей;
- подключение источника спортивных данных;
- исключение неподходящих соревнований;
- анализ через модель OpenRouter;
- автоматическое формирование прогнозов;
- автоматическое обновление результатов;
- пересчёт виртуального банка;
- накопление статистики;
- ежедневный запуск через GitHub Actions.

## Важное предупреждение

Проект является экспериментальным.

Материалы сайта:

- не гарантируют выигрыш;
- не являются финансовой рекомендацией;
- не являются призывом к азартным играм;
- не используют реальные денежные средства.

Виртуальный банк предназначен исключительно для проверки качества аналитической модели.
